# My engineering journey
[Overview](Home.md) · [Projects](Projects.md) · [Skills](Skills.md)

My work has grown from interactive web interfaces into full-stack applications, asynchronous backend services, and AI workflows. Across those projects, I focus on how the pieces fit together: what the user sees, how the application handles data, and how the backend coordinates the work.

## Building interfaces around real interactions

With React and Next.js, I worked on interfaces that do more than display information. TripCoach connects travel preferences to an interactive map. My XML form turns user input into a structured document. These projects brought together routing, form handling, validation, and data exchange—the details that make an interface useful.

[TripCoach](https://github.com/batukir/tripcoach) · [XML Form](https://github.com/batukir/dp-technical)

## Connecting the frontend to the application domain

My full-stack work expanded into GraphQL APIs, database relationships, authentication, and dashboard state. The project manager connects clients and projects through queries and mutations. The social application combines profile and feed screens with an Express/MongoDB backend. The analytics dashboard organizes sales, customer, and product data into dedicated views.

That work strengthened my focus on the contract between frontend and backend: how records are represented, how updates flow through the application, and how the interface presents the results.

[GraphQL Project Manager](https://github.com/batukir/CRUD-GraphQL) · [Social Media App](https://github.com/batukir/social-media-app) · [Analytics Dashboard](https://github.com/batukir/redux-dashboard)

## Developing Python services and background workflows

Football Clubs brings my React and Django work together through relational models, API serializers, reusable forms, and table views. The backend returns relationship IDs for editing alongside readable country, league, and characteristic details for display.

PulseCheck extends that backend focus into asynchronous execution. It moves HTTP checks into Redis-backed workers and coordinates them through schedules and completion hooks. Digest aggregation, task chains, and queue inspection make recurring work an explicit part of the application design.

[Football Clubs](https://github.com/batukir/football-clubs-react-django) · [PulseCheck](https://github.com/batukir/pulsecheck)

## Applying that foundation to AI systems

NewsLens brings my application engineering background into LLM workflows. It separates claim extraction, comparison, and grading into LangGraph stages, carries source quotations through the analysis, and includes labeled examples for evaluation.

My current focus is bringing models into applications with clear responsibilities, structured data, and ways to inspect their output. Retrieval, agent memory, and graph-based control flow are part of that direction.

[NewsLens](https://github.com/batukir/llm-agent-news-contradiction-detector) · [LangGraph work](https://github.com/batukir/LangGraph-workshop)
